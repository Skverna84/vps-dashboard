> **Ультра-легковесный веб-дашборд для мониторинга ресурсов, управления проектами и Docker-контейнерами, просмотра логов и анализа безопасности Linux VPS.**

> Разработан без тяжелых фреймворков и сторонних зависимостей (только стандартная библиотека Python 3). Потребляет всего **~2 МБ RAM** и 0% CPU в простое. Идеально подходит для маломощных VPS (512 МБ – 1 ГБ RAM).

---

## ⚡ Быстрая установка в 1 команду (Quick Install)

Выполните команду на вашем сервере под `root` (или с `sudo`):

```bash
curl -sSL https://raw.githubusercontent.com/Skverna84/vps-dashboard/main/install.sh | bash
```

Скрипт автоматически:
1. Проверит и при необходимости установит Python 3.
2. Скопирует файлы в `/opt/vps-dashboard/`.
3. Сгенерирует безопасный пароль администратора.
4. Создаст и запустит службу systemd `vps-dashboard.service`.
5. Откроет порт в UFW (если активен).
6. Выведет готовый URL и данные для входа.

### Установка со своими параметрами (Custom Install)

```bash
curl -sSL https://raw.githubusercontent.com/Skverna84/vps-dashboard/main/install.sh | bash -s -- --port 8080 --user admin --pass MySecretPassword123
```

## 🌟 Возможности версии v1.2.0

### 1. 🐳 Расширенное управление Docker
* **Интерактивный менеджер контейнеров:** модальное окно со списком всех контейнеров (`docker ps -a`), их статусами, образами и проброшенными портами.
* **Управление контейнерами в 1 клик:** запуск `[Start]`, остановка `[Stop]` и перезапуск `[Restart]` любого контейнера.
* **Логи контейнеров:** просмотр последних 100 строк логов (`docker logs --tail 100`) с временными метками и кнопкой обновления.

### 2. 🌍 Интеграция GeoIP и флаги стран
* **Определение локации атак:** автоматическое распознавание страны происхождения для всех заблокированных IP-адресов в Fail2ban и ленты попыток несанкционированного входа (`btmp`).
* **Эмодзи-флаги стран:** наглядные флаги (например, 🇳🇱 Нидерланды, 🇨🇳 Китай, 🇺🇸 США, 🇷🇺 Россия) рядом с каждым IP-адресом.
* **Кэширование в памяти:** нулевая задержка интерфейса за счет локального кэша GeoIP.

### 3. 📊 Расширенный мониторинг ресурсов (Observability)
* **Мини-графики нагрузки (HTML5 Canvas Sparklines):** живые графики истории CPU и RAM прямо внутри карточек (без внешних JS-библиотек).
* **Сетевой трафик в реальном времени (Network I/O):** текущая скорость загрузки и отдачи (⬇️ RX / ⬆️ TX в KB/s или MB/s) и счетчики общего объема переданных данных.
* **Топ-5 процессов:** таблица самых ресурсоемких процессов по CPU и RAM (PID, имя, пользователь, % нагрузки).
* **Слушающие сетевые порты (Listening Ports):** интерактивный список всех открытых портов и служб (`ss -tulpn`).
* **Накопитель, Swap и Uptime:** объем диска, занятость inodes, файл подкачки и непрерывный аптайм.

### 4. 📦 Управление проектами и DevOps
* **📜 Просмотр логов служб в 1 клик (Live Logs Viewer):** модальное окно с выводом последних 100 строк системного журнала (`journalctl -u <service>`) для каждого сервиса.
* **Авто-распознавание проектов:** RustDesk Server, GoHTTPServer, Docker Engine, Nginx, Fail2ban.
* **Кнопки управления:** `[Логи]`, `[Перезапуск]`, `[Остановить]`, `[Запустить]`.
* **➕ Динамическое добавление служб:** кнопка добавления любой systemd-службы (например, `wireguard`, `cron`, `ufw`) для управления из панели.
* **💾 Бэкап в 1 клик (Backup Manager):** мгновенное скачивание архива конфигураций и баз данных (`.tar.gz`) прямо через браузер.
* **🔄 Самообновление панели:** кнопка «Обновить панель» загружает актуальный код из GitHub и перезапускает службу в 1 клик.

### 5. 🛡️ Центр безопасности и Fail2ban
* **Управление блокировками:** список всех заблокированных IP-адресов с флагами стран и кнопкой `[Разблокировать]`.
* **Ручной бан (Custom Ban):** поле ввода IP для мгновенной блокировки любого подозрительного хоста на 24 часа.
* **Лента атак:** история последних неудачных попыток подбора логинов и паролей с определением стран.
* **🔑 Журнал успешных входов (Audit Log):** история успешных SSH-сессий (пользователь, IP, время).

### 6. 🎨 Удобство и гибкость (UI/UX)
* **Настройка частоты обновления:** выбор интервала опроса (`1 сек`, `3 сек`, `5 сек` или `Пауза`).
* **🇷🇺 / 🇬🇧 Двуязычный интерфейс:** переключатель **RU / EN** на лету.
* **🌙 / ☀️ Темы оформления:** темная и светлая темы с сохранением выбора.
* **🔒 Безопасность:** HTTP Basic Auth + безопасные Cookie-токены.

## 📋 Системные требования

* **ОС:** Любой современный Linux (Ubuntu 20.04+, Debian 11+, CentOS 8+, AlmaLinux, Rocky Linux, Fedora).
* **Python:** 3.8 или новее (используется только встроенная библиотека: `http.server`, `json`, `subprocess`, `tarfile`).
* **Система инициализации:** systemd.
* **Оперативная память:** от 256 МБ RAM (дашборд занимает менее 2 МБ).

## 🛠️ Ручная установка (Manual Installation)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Skverna84/vps-dashboard.git /opt/vps-dashboard
cd /opt/vps-dashboard

# 2. Создайте файл конфигурации
cp config.example.json config.json
nano config.json # укажите свой порт, логин и пароль

# 3. Настройте службу systemd
cp vps-dashboard.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now vps-dashboard.service

# 4. Откройте порт в файрволе (если используется UFW)
ufw allow 8080/tcp comment "VPS Web Dashboard"
```

## ⚙️ Управление службой дашборда

```bash
# Проверить статус
systemctl status vps-dashboard

# Перезапустить
systemctl restart vps-dashboard

# Остановить
systemctl stop vps-dashboard

# Просмотреть логи
journalctl -u vps-dashboard -f
```
